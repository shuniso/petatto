# ペタッと (petatto)

ホットキーで呼び出し、インクリメンタルサーチで選んで貼り付けるだけの、Windows 11 用スニペットランチャー。

- 単一の exe(ランタイム・インストーラー不要)
- スニペットはテキストファイル 1 つ。編集 UI は持たない
- Rust + Win32 API のみ

## 使い方

1. `petatto.exe` を好きなフォルダーに置いて起動する(タスクトレイに常駐)
2. `Ctrl+Alt+Space` でポップアップを開く
3. 文字を打って絞り込み、`↑` `↓` で選び、`Enter` で貼り付け

| キー | 動作 |
| --- | --- |
| 文字入力 | 絞り込み(空白区切りで AND、大文字小文字は区別しない) |
| `↑` `↓` `PageUp` `PageDown` | 選択の移動 |
| `Enter` / クリック | 貼り付け |
| `Esc` / ホットキーをもう一度 / 他のウィンドウをクリック | 閉じる |

終了・設定ファイルを開く・再読み込みは、タスクトレイのアイコンのメニューから。

ログイン時に自動起動したい場合は、`Win+R` → `shell:startup` で開くフォルダーに exe のショートカットを置く。

## スニペットの書き方

exe と同じフォルダーの `snippets.toml`(初回起動時にサンプルが作られる)を UTF-8 で編集する。
保存すれば、次にホットキーを押したときに反映される。

```toml
hotkey = "Ctrl+Alt+Space"

[[snippet]]
name = "メールアドレス"
text = "taro@example.com"

[[snippet]]
name = "挨拶"
text = '''
お世話になっております。
山田です。
'''
```

- `name` は検索・表示用。省略すると本文の 1 行目が使われる
- 名前で一致したものが先、本文だけで一致したものが後に並ぶ
- `'''` で囲んだ本文はエスケープなしでそのまま貼り付けられる。末尾の改行 1 つは取り除く
- `hotkey` は修飾キー(`Ctrl` `Alt` `Shift` `Win`)+ キー(`A`-`Z` `0`-`9` `F1`-`F24` `Space`)
- 書式エラーがあるときは、ポップアップにエラー内容が表示される

## 制限

- 貼り付けは「クリップボードに置いて `Ctrl+V` を送る」方式。元のクリップボードはテキストなら約 0.5 秒後に書き戻すが、画像やファイルなどテキスト以外だった場合は書き戻せない
- 管理者権限で動いているウィンドウには貼り付けられない(ペタッと自体を管理者として起動すれば可能)
- 貼り付けが `Ctrl+V` でないアプリ(一部のターミナルなど)では貼り付けられない

## ビルド

`main` への push と Pull Request で GitHub Actions が `petatto.exe` をビルドし、Artifact として保存する。
`v0.1.0` のような `v*` タグを push すると、Release に exe が添付される。

Windows 上で手元ビルドする場合:

```
cargo build --release
```

設定の解釈や検索などの OS 非依存部分(`src/config.rs`)は、どの OS でも `cargo test` で確認できる。
